
---
name: investigate
description: Investigate a feature request before implementation.
---

Read docs/specs.md and the repository instructions.

For the supplied feature request:
1. Summarize the requirement.
2. Identify relevant files.
3. Propose the smallest implementation.
4. List acceptance criteria and tests.
5. Identify security risks and assumptions.

Do not modify files until the plan is reviewed.
Do not claim to have run tests unless you actually ran them.
